ADF的原假设为单位根，KPSS的原假设为水平平稳；二者不能按同一方向解读。tseries的部分p值被表格范围截断，CSV中0.01等边界值不是无限精确的尾部概率。结构变化和有限样本也会影响检验。风险指数对数水平有明显持久性证据，尚未验证其适合稳定水平系统的正式设定；按用户已确认的对数水平方案保留探索估计，不擅自改成差分。

每套模型72个方程、各4/8阶两项OLS残差BG筛查，共144项。CN和US两套各有42项在BH调整后p<.05。这是条件OLS的描述性预检，不是实际TVP后验残差检验，也不是弱外生性或结构识别证明。CPI、利率和部分产出方程的动态设定需进一步研究，不应把一阶滞后当成已通过充分诊断的正式最优选择。

peak_event_context.csv为16个入选峰值保存可核验的同期事件背景、日期与第一方来源。2017Q1中国EPU对应年度政策议程等背景，并不宣称某个事件已被证明造成指数峰值。所有背景都不是结构性冲击识别；统计峰值日期不等同于事件发生日期或外生冲击日期。该表不参与选峰，也不读取IRF符号或显著性。

本目录保存的是预检和背景资料，不是MCMC完成证明。实际抽样、单链ESS、稳定比例和IRF结果应另行读取对应运行的估计产物。
